## Projects

### 1. **NewVisayasPetConnect** - A Street-to-Home Rescue, Adoption, and Donation System

**Overview:**  
A web-based management system designed for Barangay New Visayas, Panabo City, to streamline animal rescue, pet adoption, and donation efforts. By providing a centralized digital platform, the system allows residents to report stray or lost animals while enabling administrators to manage adoption profiles and track donation allocations with full transparency.

**Tech Stack:**
- **Framework:** PHP, HTML/CSS
- **Database:** MySQL
- **Type:** Web App
- **Goal:** Efficiency

**Key Features:**
- Report stray or lost animals
- Manage pet adoption profiles
- Track and allocate donations transparently
- Streamlined admin dashboard
- Community-focused interface

**Impact:**  
Transforms the barangay into a more organized and compassionate environment for both people and pets by leveraging technology to enhance community safety, promote animal welfare, and ensure efficient resource management.

### 2. **Flood Tracker and Relief Distribution Web System**

**Overview:**  
A digital platform designed to enhance community resilience by streamlining flood reporting and the allocation of aid during emergency situations. By providing a centralized hub for real-time flood monitoring, official announcements, and transparent relief distribution management, the system replaces inefficient manual processes with a reliable interface for both residents and barangay officials.

**Tech Stack:**
- **Language:** PHP, HTML/CSS
- **Tools:** MySQL
- **Type:** Web App
- **Goal:** Efficiency

**Key Features:**
- Real-time flood monitoring and reporting
- Official announcements and alerts
- Transparent relief distribution management
- Centralized admin interface
- Community-accessible information hub

**Impact:**  
Ensures that affected families receive timely information and equitable access to resources, fostering a more organized, responsive, and accountable disaster response framework for the community.
